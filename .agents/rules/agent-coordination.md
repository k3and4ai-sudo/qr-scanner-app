# 司令塔と並列タスク運用規約 (Agent Coordination Rules)

本規約は、Claude Code Projects の「コーディネーター（司令塔）と並列スレッド」の概念を Antigravity 上で実践・最適化するための行動指針です。

## 1. エージェントの役割分担

- **メインエージェント（司令塔 / コーディネーター）**:
  - ユーザーからの要望受付、意図の整理、要件定義
  - 共有メモリ（Rules, Docs, Memory）の確認と整合性の検証
  - タスクの分解、サブエージェントおよびバックグラウンドタスクのオーケストレーション
  - 成果物の統合、ビルド・品質チェック、ユーザーへの報告
- **サブエージェント / 実行系タスク（ワーカー）**:
  - 単一責務に特化したコード実装・修正
  - ブラウザ自動操作によるUIレンダリング・動作検証 (`browser_subagent`)
  - バックグラウンド実行（開発サーバー、テスト、ビルド検証）

## 2. タスク分解と並列実行の基準

以下のいずれかに該当する場合、司令塔はタスクを分解し、並行または段階的に実行します：
1. **影響範囲が2つ以上の独立コンポーネントにまたがる場合**（例: UI変更とユーティリティ関数追加）
2. **調査・実証コードの作成と、本番コードの実装が分かれている場合**
3. **コード修正と同時に、ブラウザでの画面崩れやコンソールエラーの検証が必要な場合**

## 3. オーケストレーション手順

1. **タスク計画の立案**:
   - 何をどの順番で実行するか、並行して実行できるものは何かを整理する。
   - 作業用トピックブランチ（`git-workflow.md` 参照）を作成する。
2. **ワーカーへの指示**:
   - サブタスクごとに明確なスコープと完了条件（Definition of Done）を設定する。
3. **統合と検証**:
   - 全サブタスクの完了後、メインエージェントが全体を結合し、`npm run build` を実行してエラーのないことを確認する。
