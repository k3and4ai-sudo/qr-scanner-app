# ⚡ QR Master Studio - 取扱説明書 (ユーザーマニュアル)

---

## 📖 概要

**QR Master Studio** は、Web API ハードウェア加速 (`window.BarcodeDetector`) と最適化済み `jsQR` デュアルエンジンを搭載した、超高速 **PWA (Progressive Web App)** QRコードスキャン＆発行アプリケーションです。

スマホ・PCのブラウザからカメラをかざすだけで、数ミリ秒の超高速デコードとリアルタイム環境光補正（自動露出最適化）、ならびに**URL自動安全性診断・フィッシング詐欺防止機能**を提供します。

さらに、**ホーム画面インストール（PWA）による完全オフライン動作（0秒起動）**、スキャン履歴の**Excel文字化け防止 CSV/JSON 出力**、**Wi-Fi・名刺QR作成の構文解説モーダル**、**安全スコア100点満点以外のURLジャンプ警告確認ゲート**など、実用性とセキュリティを兼ね備えた最新鋭のツールです。

## 🚀 主な機能と使い方

### 1. 📷 QRコードスキャン & ⚡ ワンタップ即時スキャン開始

#### 🔹 基本的なスキャン手順
1. 上部ナビゲーションの **「QRスキャナー」** ボタンをクリックします。
2. クリックした瞬間にカメラモーダルへ即座に切り替わり、**自動的に Web カメラが起動してリアルタイム解読がスタート**します。
3. QRコードをカメラ枠内に収めると、**ミリ秒単位で瞬時に自動解読**されます。

> [!TIP]
> **⚡ 自動露出最適化 (Auto Exposure System) について**
> - カメラ起動時、デフォルトで `⚡ 自動露出 (Auto)` が選択されています。
> - 周囲の明るさ（輝度 0〜255）をリアルタイム計算し、強い照明・直射光による白飛び時には自動で `-2.0 EV` (暗調補正)、暗所では `+2.0 EV` (明暗補正) を動的適用します。
> - 読み込みが滞留した場合は、システムが最適な露出設定を自律探索（オートスワイプ）します。

#### 🔹 露出補正のボタン構成
| ボタン名 | 設定値 | 利用シーン |
| :--- | :--- | :--- |
| **`🔆 標準 (0.0 EV)`** | 明るさ 100% / コントラスト 100% | 通常の室内・適切な光量環境 |
| **`🕶️ 暗く (-2.0 EV)`** | 明るさ 50% / コントラスト 140% | パソコン画面の反射・PCモニターの白飛び |
| **`☀️ 明るく (+2.0 EV)`** | 明るさ 150% / コントラスト 120% | 暗い室内・影でQRコードが暗い場合 |
| **`⚡ ハイコントラスト (-0.6 EV)`** | 明るさ 85% / コントラスト 170% | 印字がかすれている紙媒体・シール |
| **`⚡ 自動露出 (Auto)`** *(デフォルト)* | リアルタイム動的最適化 | あらゆる環境（最も推奨されるモード） |

### 2. 📁 画像ファイルからの QR 読み込み (File Scanner)

1. 上部ナビゲーションの **「ファイル読み込み」** ボタンを選択します。
2. スマートフォン内の**写真アルバム、フォルダー、スクリーンショット**から画像ファイルを選択するだけで、瞬時にQRコードを解読します。
3. メールの添付画像、LINE のトーク画面で受信した画像、保存した電子チラシのQRコードも端末内で手軽にスキャン可能。
4. PC ブラウザでは、**画像のドラッグ＆ドロップ**や、**クリップボードからの画像貼り付け (`Ctrl + V`)** にも対応しています。

### 3. 🛡️ URL 安全性自動診断 & 100点未満ジャンプ警告確認ゲート

QRコードに含まれるURLの安全性を**8項目の包括的セキュリティアルゴリズム**で自動診断・スコアリング（0〜100点）します。

#### 🔹 8つの自動セキュリティ検証項目
1. **🔒 通信暗号化 (HTTPS)**: HTTPS（SSL/TLS暗号化）通信であるか判定。
2. **💻 数値IPアドレス接続検出**: 正規ドメインではなく `http://192.168.1.1` などの数値IP直接接続（フィッシング詐欺で多用）を検出。
3. **🌐 Punycode (文字偽装) 検出**: `xn--...` などの国際化ドメイン（大手ブランドの類似文字を用いた偽装サイト）を自動識別。
4. **⚠️ 高リスク TLD チェック**: `.zip`, `.mov`, `.tk`, `.top`, `.work`, `.click` など不審なWebサイトで多用されるトップレベルドメインを警戒。
5. **📦 危険なファイル拡張子検出**: `.exe`, `.apk`, `.bat`, `.vbs`, `.zip` など不正なダウンロード直リンクを検出。
6. **🚨 フィッシングキーワード検出**: `login-verify`, `verify-account`, `crypto-claim` 等の詐欺キーワードを検出。
7. **🌲 多重サブドメイン構成チェック**: 偽装目的の多重ネストされた怪しいサブドメインを識別。
8. **🏛️ 信頼ドメイン検証 ＆ 外部DB連携**: メジャーな正規ドメインの構造検証に加え、**Google Safe Browsing**, **VirusTotal**, **urlscan.io**, **Norton Safe Web** で1タップ照会が可能。

#### 🔹 安全スコア判定分類
- 🟢 **安全 (100点満点)**: 脅威パターンなし。ダイレクトにアクセス可能。
- 🟡 **要確認・注意 (60〜99点)**: HTTP通信、不審TLD、クエリパラメータ等が含まれるURL。
- 🔴 **危険・高リスク (0〜59点)**: 不審なパターンやスクリプト、フィッシング疑いが検出されたURL。

> [!WARNING]
> **⚠️ 安全スコア100点満点以外のアクセス警告確認ゲート**
> 
> 安全スコアが**完全満点（100点）以外のすべてのURL**を開こうとした場合、スキャン直後の結果画面および履歴画面の双方で、誤アクセスを未然に防止する**安全警告ポップアップ画面**が自動起動します。
> 画面上でスコア数値や検出理由を確認した上で、「Google Safe Browsing で事前確認」「リスクを承知の上でアクセス」「キャンセル」を安全に選択できます。

### 4. 🎨 QRコード作成ツール ＆ テンプレート構文解説モーダル

1. ナビゲーションの **「QR作成」** を選択します。
2. 発行したい種別（**URL / 自由テキスト / Wi-Fi自動接続情報 / vCard名刺連絡先**）を選択し、内容を入力します。
3. **💡 テンプレート解説・自動入力支援**:
   - Wi-Fi や 名刺（vCard）を選択すると、**「💡 入力方法・キーワード解説」** ボタンが表示されます。
   - クリックすると、`WIFI:T:WPA;S:MySSID;P:password;;` や `BEGIN:VCARD...` などの各キーワードの意味や書式ルールを分かりやすく解説したモーダルが起動。
   - フォームに入力して「反映する」を押すだけで、正しい構文規則に準拠したQRコード文字列がワンクリックで自動入力されます。
4. 前景色（コード色）や背景色を自由にカラーパレットから選べます。
5. **「PNG ダウンロード」** ボタンを押して、高解像度画像を端末に保存します。

### 5. 📜 スキャン履歴の管理・メモ機能・CSV/JSON出力・ゴミ箱

#### 🔹 タイトル＆コメント（メモ）のインライン記録
- スキャンした内容はブラウザ内 (`LocalStorage`) に安全に自動保存されます。
- 各スキャンの「編集」ボタンから、**任意のタイトルやコメント・メモを自由に追記・保存**できます。
- スマホでも文字が隠れずスムーズに入力できるよう、広幅・適正フォントサイズの入力欄を採用しています。
- 秒単位の完全スキャン日時（`YYYY/MM/DD HH:mm:ss`）も同時に記録されます。

#### 🔹 📥 CSV エクスポート（UTF-8 BOM付き・Excel文字化け完全防止）
- 履歴画面上部の **「CSV出力」** ボタンを押すと、表示中のスキャン履歴一覧がワンクリックで CSV ファイルとしてダウンロードされます。
- **UTF-8 BOM (`\uFEFF`)** を付与して生成しているため、**Windows / Mac の Microsoft Excel や各種スプレッドシートでそのまま開いても、日本語が一切文字化けしません**。

#### 🔹 📥 JSON エクスポート
- 解析メタデータ（`parsedData`）、安全診断スコア、判定理由を含む構造化データを **JSON 形式** で丸ごとエクスポートできます。

#### 🔹 🗑️ ゴミ箱機能
- 不要になった履歴アイテムは「ゴミ箱」へ安全に一時退避できます。
- 「ゴミ箱」タブに切り替えることで、**「元に戻す」「完全に削除」「ゴミ箱を空にする」** の操作が可能です。

### 6. 📲 PWA（Progressive Web App）機能 & 完全オフライン動作

- **ホーム画面インストール**:
  ヘッダーの「📲 ホーム画面に追加」ボタンから端末へ直接インストール可能。アドレスバーのないネイティブアプリ全画面として起動できます。
- **完全オフライン動作（0秒起動）**:
  Service Worker（`sw.js`）により静的アセットが高精度キャッシュされているため、**地下街や山間部、飛行機内（機内モード）など、電波の届かないオフライン環境下でもアプリが即座に起動・動作**します。
- **新バージョン自動検知トースト**:
  新バージョンが GitHub Pages にデプロイされると、画面下部に **「🔔 新バージョンがあります [今すぐ更新]」** トーストバナーがスライドインし、タップするだけで最新版へ安全に切り替わります。

### 7. ⚡ 超高速デコード技術 & 白飛び復元エンジン

- **`BarcodeDetector API` (GPUハードウェア加速)**:
  ブラウザ標準の組み込み API を最優先活用。GPU を駆使してミリ秒単位で超高速な検出・認識を行います。
- **白飛び復元エンジン (適応二値化ガンマアルゴリズム & 物理EV制御)**:
  PC画面の強い反射や露出オーバーに対しても、物理露光 (`-2.0 EV` 〜 `+2.0 EV`) を補正し、階調差を強調して高精度解読を完遂させます。
- **大津適応二値化フォールバック**:
  非対応端末でも、最適化済み `jsQR` と独自画像処理により高精度に解読を継続します。

## 🛠️ トラブルシューティング & FAQ

> [!WARNING]
> **Q. 「カメラの起動に失敗しました」または「HTTPS接続が必要です」と表示される場合**
> 
> **原因**: Android Chrome や iOS Safari 等のスマホブラウザでは、セキュリティ制限（Secure Context）により、`http://192.168.0.x:3000` などの IP アドレス直接アクセスによるカメラ使用が自動拒否されます。
> 
> **解決策**: 
> 本アプリの公式本番 HTTPS URL (`https://k3and4ai-sudo.github.io/qr-scanner-app/`) またはローカル開発の HTTPS URL (`https://localhost:3000/`) からアクセスしてください。HTTPS 接続下であれば、カメラ権限および GPU ハードウェア加速 API が正常に作動します。

> [!NOTE]
> **Q. LINE アプリ内ブラウザ（LINE WebView）でカメラが動かない場合**
> 
> **原因**: LINE アプリ内部の WebView 仕様により、カメラ権限が一時的に制限される場合があります。
> 
> **解決策**: 画面上部に表示される「🌐 他のブラウザ（Chrome / Safari）で開く」ボタンを押すか、右上のメニューから「ブラウザで開く」を選択してください。

> [!TIP]
> **Q. エクスポートした CSV ファイルを Excel で開くと文字化けしませんか？**
> 
> **回答**: 文字化けしません。本アプリの CSV 出力機能は **UTF-8 BOM (`\uFEFF`)** を自動付与しているため、Windows 版および Mac 版の Microsoft Excel、Google スプレッドシートなどでダブルクリックして開くだけで、日本語タイトルやコメントが正常に表示されます。

> [!IMPORTANT]
> **Q. スキャンしたURLにすぐジャンプせず警告が出るのはなぜですか？**
> 
> **回答**: 悪質なフィッシング詐欺サイトや不正スクリプトへのアクセス事故を防止するため、**安全スコアが完全満点（100点）以外のすべてのURL**について、事前に警告確認モーダルを割り込ませて表示しています。安全スコアと検出項目を確認した上で、リスクを承知の上でアクセスするかキャンセルかをご自身で判断できます。
