⚡ QR Master Studio - 取扱説明書 (ユーザーマニュアル)

📖 1. 概要

QR Master Studio は、Web API ハードウェア加速 (window.BarcodeDetector) と最適化済み jsQR デュアルエンジンを搭載した、超高速 PWA (Progressive Web App) QRコードスキャン＆発行アプリケーションです。

スマホ・PCのブラウザからカメラをかざすだけで、数ミリ秒の超高速デコードとリアルタイム環境光補正（自動露出最適化）、ならびにURL自動安全性診断・フィッシング詐欺防止機能を提供します。

画面上部に並ぶナビゲーションボタン（ボタン名）の順序に沿って、各ボタンを押したときのジャンプ先画面と、それに関連する全機能をわかりやすく説明します。

画面最上部には、操作性に優れた2段グリッドの特大ナビゲーションボタンと、ヘッダー右上の PWA インストールバッジが配置されています：

段 / 位置 ナビゲーションボタン名 アイコン ジャンプ先と主な役割

[上段右] ファイル読み込み <FolderOpen /> 画像ファイル解読画面（アルバム・写真・スクショ・D&D・クリップボード貼付）

🚀 3. ボタン別 使い方・関連機能ガイド

① QRスキャナー (上段左ボタン)

上部ナビゲーションの 「QRスキャナー」 ボタンをクリックすると、カメラ映像によるリアルタイムQRコード解読画面へジャンプします。

🔹 1. カメラ自動起動 ＆ ミリ秒単位の超高速デコード

  • ボタンを押した瞬間に Web カメラが自動的に起動し、連続フレーム解析がスタートします。
  • QRコードをカメラ枠内に収めるだけで、ミリ秒単位で瞬時に自動解読されます。
  • ブラウザ組み込みの window.BarcodeDetector（GPUハードウェア加速）を最優先活用し、非対応端末でも大津適応二値化 jsQR フォールバックにより高精度に解読を完遂します。

🔹 2. ⚡ 自動露出最適化 (Auto Exposure System) ＆ 白飛び復元

  • PC画面のギラつきや直射日光による白飛び、暗所環境に対し、デフォルトで選択されている ⚡ 自動露出 (Auto) が環境光の輝度（0〜255）をリアルタイム測定し、物理露光補正 (-2.0 EV 〜 +2.0 EV) を動的に適用して確実に解読します。
  • 画面下のボタンから手動で露出設定（標準 / 暗く / 明るく / ハイコントラスト）を切り替えることも可能です。

🔹 3. 🛡️ URL安全性自動診断 ＆ 100点未満ジャンプ警告確認ゲート

  • スキャンした内容が URL の場合、8項目のセキュリティチェックアルゴリズム（HTTPS暗号化、数値IP接続、Punycode文字偽装、高リスクTLD、危険拡張子、フィッシングキーワード、多重サブドメイン、メジャードメイン検証）により 0〜100点の安全スコア を自動算出します。
  • 安全スコア分類:
  • 🟢 安全 (100点満点): 脅威パターンなし。直接URLを開くことができます。
  • 🟡 要確認・注意 (60〜99点): HTTP通信、不審TLD、クエリパラメータ等が含まれるURL。
  • 🔴 危険・高リスク (0〜59点): 不審なパターンやスクリプト、フィッシング疑いが検出されたURL。
  • ⚠️ 100点満点以外のアクセス警告確認ゲート:
    安全スコアが完全満点（100点）以外のすべてのURLを開こうとした場合、誤アクセスを防止する安全警告ポップアップ画面が自動起動します。検出理由とスコアを確認した上で、「Google Safe Browsing で事前調査」「リスクを承知の上でアクセス」「キャンセル」を安全に選択できます。

② ファイル読み込み (上段右ボタン)

上部ナビゲーションの 「ファイル読み込み」 ボタンをクリックすると、画像ファイルからのQRコード解読画面へジャンプします。

🔹 1. スマートフォンのアルバム・スクリーンショットから直接解読

  • スマートフォン内の写真アルバム、フォルダー、保存したスクリーンショットから画像ファイルを選択するだけで、瞬時にQRコードを解読します。
  • メールの添付画像、LINE のトーク画面で受信した画像、電子チラシやクーポンのQRコードも端末内で手軽にスキャンできます。

🔹 2. PCでのドラッグ＆ドロップ ＆ クリップボード貼り付け (Ctrl + V)

  • パソコン環境では、破線エリアへ画像ファイルを直接ドラッグ＆ドロップするか、Webページ上の画像をコピーして Ctrl + V（Mac は Cmd + V）を押すだけで、ファイルを保存することなく即座に解読されます。

🔹 3. 共通の結果カード ＆ URL安全性診断

  • ファイル解読後も「QRスキャナー」と同一の結果カードが表示され、ワンクリックコピーやURLパラメータ構造解析、100点未満ジャンプ警告確認ゲートが同様に作動します。

③ QR作成 (下段左ボタン)

上部ナビゲーションの 「QR作成」 ボタンをクリックすると、独自のQRコードを自由に生成・保存できるツール画面へジャンプします。

🔹 1. 4つのデータ種別に対応（URL / テキスト / Wi-Fi / 名刺）

  • Webサイトの URL、自由なテキストメモ、店舗や自宅の Wi-Fi 接続設定、vCard 名刺連絡先データの4種類から選んで、高精度QRコードをリアルタイム生成します。

🔹 2. 💡 Wi-Fi ＆ vCard テンプレート構文解説 ＆ 自動入力支援モーダル

  • Wi-Fi または 名刺（vCard）を選択すると、「💡 入力方法・キーワード解説」 ボタンが表示されます。
  • ポップアップ内で WIFI:S:SSID;T:WPA;P:password;; や BEGIN:VCARD... などの構文キーワード（SSID, 暗号化, パスワード / 氏名, TEL, メール等）の意味を詳細に解説。
  • 専用入力フォームに項目を入力して「反映する」を押すだけで、正しい規格準拠の文字列がワンクリックで自動作成されます。

🔹 3. カラーカスタマイズ ＆ 高解像度 PNG ダウンロード

  • QRコードの前景色と背景色をカラーピッカーから自由にカスタマイズ可能。
  • 「PNG ダウンロード」ボタンを押すことで、印刷物やPOP、Web素材に最適な高画質 PNG 画像として端末にワンクリック保存できます。

④ 履歴 (下段中央ボタン)

上部ナビゲーションの 「履歴」 ボタンをクリックすると、過去にスキャンしたQRコードの一覧管理・メモ編集・エクスポート画面へジャンプします。

🔹 1. タイトル＆コメント（メモ）のインライン編集・保存

  • 各スキャン結果に、任意の「タイトル」や「コメント（メモ）」を追記・編集・保存できます。
  • スマートフォンでも文字がキーボードに隠れないよう、上下幅の広いテキストエリア（minHeight: 100px）と見やすいフォントを採用しています。
  • スキャンした日時も秒単位（YYYY/MM/DD HH:mm:ss）で正確に記録されます。

🔹 2. 📥 CSV エクスポート（UTF-8 BOM付き・Excel文字化け完全防止）

  • ツールバーの 「CSV出力」 ボタンを押すと、スキャン履歴一覧がワンクリックで CSV ファイルとしてダウンロードされます。
  • UTF-8 BOM (\uFEFF) を自動付与しているため、Windows 版および Mac 版の Microsoft Excel、Google スプレッドシートなどでダブルクリックして開くだけで、日本語が一切文字化けしません。

🔹 3. 📥 JSON エクスポート

  • 解析メタデータ（parsedData）、安全診断スコア、判定理由を含む構造化データを JSON 形式 で丸ごとエクスポートできます。

🔹 4. ⚠️ 100点未満URLのジャンプ確認ゲート（履歴内でも作動）

  • 履歴一覧の「開く」ボタンを押した際も、安全スコアが100点満点以外のURLには警告確認ダイアログが表示されます。過去のスキャンであっても安全確認を行ってからアクセスできます。

🔹 5. 🗑️ ゴミ箱機能（一時退避・復元・完全削除・一括クリア）

  • 不要になった履歴アイテムは「ゴミ箱」へ安全に一時退避できます。
  • 「ゴミ箱」タブに切り替えることで、個別の「元に戻す（復元）」「完全に削除」や、「ゴミ箱を空にする」一括消去が可能です。

ヘッダー右上の 「📲 ホーム画面に追加」 ボタンをクリックすると、端末への PWA インストールを実行できます。

🔹 1. ネイティブアプリ化 ＆ 完全オフライン動作 (0秒起動)

  • ホーム画面に追加すると、アドレスバーのない全画面ネイティブアプリとして起動します。
  • Service Worker（sw.js）によるオフラインキャッシュにより、地下街や飛行機内（機内モード）など電波の届かないオフライン環境でも0秒で起動・動作します。

🔹 2. 新バージョン自動検知トーストバナー

  • アプリの新機能が配信されると、画面下部に「🔔 新バージョンがあります [今すぐ更新]」トーストバナーがスライド表示され、ワンタップで最新版へ即時更新できます。

🛠️ 4. トラブルシューティング & FAQ

⚠️ [WARNING]
Q. 「カメラの起動に失敗しました」または「HTTPS接続が必要です」と表示される場合

原因: Android Chrome や iOS Safari 等のスマホブラウザでは、セキュリティ制限（Secure Context）により、http://192.168.0.x:3000 などの IP アドレス直接アクセスによるカメラ使用が自動拒否されます。

解決策:
本アプリの公式本番 HTTPS URL (https://k3and4ai-sudo.github.io/qr-scanner-app/) またはローカル開発の HTTPS URL (https://localhost:3000/) からアクセスしてください。HTTPS 接続下であれば、カメラ権限および GPU ハードウェア加速 API が正常に作動します。

ℹ️ [NOTE]
Q. LINE アプリ内ブラウザ（LINE WebView）でカメラが動かない場合

原因: LINE アプリ内部の WebView 仕様により、カメラ権限が一時的に制限される場合があります。

解決策: 画面上部に表示される「🌐 他のブラウザ（Chrome / Safari）で開く」ボタンを押すか、右上のメニューから「ブラウザで開く」を選択してください。

💡 [TIP]
Q. エクスポートした CSV ファイルを Excel で開くと文字化けしませんか？

回答: 文字化けしません。本アプリの CSV 出力機能は UTF-8 BOM (\uFEFF) を自動付与しているため、Windows 版および Mac 版の Microsoft Excel、Google スプレッドシートなどでダブルクリックして開くだけで、日本語タイトルやコメントが正常に表示されます。

❗ [IMPORTANT]
Q. スキャンしたURLにすぐジャンプせず警告が出るのはなぜですか？

回答: 悪質なフィッシング詐欺サイトや不正スクリプトへのアクセス事故を防止するため、安全スコアが完全満点（100点）以外のすべてのURLについて、事前に警告確認モーダルを割り込ませて表示しています。安全スコアと検出項目を確認した上で、リスクを承知の上でアクセスするかキャンセルかをご自身で判断できます。
